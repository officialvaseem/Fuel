# Fuel Digital Marketing 🚀

> A modern, responsive digital marketing agency website built to showcase
> services, client work, testimonials, and the agency's online presence.

🌐 **Live Website:** [fueldigitalmarketing.vercel.app](https://fueldigitalmarketing.vercel.app)

---

## 📌 About

Fuel Digital Marketing is a professional agency website developed to create
a strong digital presence for a marketing business.

The website focuses on a clean user experience, responsive design,
service presentation, client showcases, testimonials, and easy contact.

## ✨ Features

- 🎨 Modern and clean UI
- 📱 Responsive design for desktop, tablet and mobile
- 💼 Digital marketing services showcase
- 🖼️ Client/project portfolio
- ⭐ Testimonials section
- 📩 Contact form integration
- 🔗 Social media and service links
- ⚡ Deployed on Vercel
- 🚀 Continuously improved and maintained

## 🛠️ Tech Stack

- **HTML5** — Structure
- **CSS3** — Styling & responsive design
- **JavaScript** — Interactivity
- **Web3Forms** — Contact form integration
- **Git & GitHub** — Version control
- **Vercel** — Deployment
